# Notebooks

This folder contains exploratory and tutorial Jupyter notebooks:

| Notebook | Description |
|----------|-------------|
| `email_generator.ipynb` | End-to-end notebook walkthrough of the email generation pipeline |
| `tutorial_chromadb.ipynb` | ChromaDB vector store tutorial and exploration |
| `tutorial_groq.ipynb` | Groq LLM API tutorial and usage examples |

> Run `python _setup_copy.py` from the project root to copy these notebooks here automatically.
